# Logistic Regression from Scratch

This project demonstrates how to implement logistic regression from scratch in Python, without using libraries like scikit-learn.

---

## What this project does

- Implements Logistic regression manually in Python
- Evaluates the model using:
  - **Confusion matrix** 
  - **Precision** 
  - **Recall**
  - **F1_score**
- Plots:
  - Log_loss evolution over epochs
- Compares custom implementation with scikit-learn

---

## Project Structure

src directory: contains the notebook and data 

## Run the project

1) Create a virtual environment using the command : python -m venv .venv

2) Download the necessary packages with the command : pip install -r requirements.txt

3) Run the notebook
